# Hétu: The Trinity Model ॐ

**Hétu** is a digital experiment in radical transparency and open-source creativity. 

This repository hosts the source code for [advaitaonacid.github.io](https://advaitaonacid.github.io), a platform designed to turn digital attention into a self-sustaining cycle of global impact.

## The Trinity Loop
1. **Rajas (Creation):** All music and Ableton project files are released under **CC0 (Public Domain)**.
2. **Sattva (Impact):** **80%** of royalties are automatically routed to humanitarian and environmental charities.
3. **Tamas (Foundation):** **20%** of revenue sustains project overheads and infrastructure.

The creative "DNA" of this project—including raw Ableton files and samples—is available for public use.
